# 【fnOS 应用发布】TvBox For Emby —— 把点播源装进你的海报墙（v0.6.0）

> 一个 fnOS 应用 + 一个 Emby 插件，装完在浏览器里点点鼠标就能用，不用碰命令行。

【截图 1：概览页 —— KPI 与配置检测】

## 为什么做这个

用过 TVBox 的都知道：源是能看，但它是"播放器"不是"媒体库"——看完就忘，没有海报墙、没有继续观看、没有多端同步进度。

反过来，Emby 的媒体库体验很好，但内容从哪来一直是道坎。

**这个项目就是把这个缝接上**：把 TVBox 生态的点播源接进 Emby，同步成标准的 `.strm` 文件。Emby 把 `.strm` 当普通视频扫描入库，于是你得到的是完整的媒体库体验——海报墙、分类、继续观看、电视/手机/平板多端同步——而播放时真正拉流的还是源站。

同一个站点单独一个目录，同一部片在几个站都有就存几份，谁挂了都不影响。

## 五步上手

1. **填点播源** —— 配置页填 TVBox 配置地址（单仓 JSON / 多仓 urls / base64 / 本机路径都认）
2. **选站点** —— 站点页勾选能用的源，建议先勾 3–5 个探测通过的试水
3. **设输出目录** —— 默认在 Emby 数据目录下，也可以指到自己的媒体盘
4. **装 Emby 插件** —— 页面上一键安装，带重启进度弹窗
5. **跑同步** —— 同步完在 Emby 里把 `<输出目录>/<站点>/movies`、`.../tv` 加成媒体库扫描即可

文件命名完全遵循 Emby 规范（`片名 (年份)`、`Season 01`、`剧名 - S01E01 - 集名`），海报、nfo 一起生成，Emby 扫出来直接就是漂漂亮亮的海报墙。

## 播放是怎么走通的

`.strm` 里默认写的是本机代理地址：插件自动补 Referer / User-Agent、重写 HLS 分片路径，**防盗链的源也能播**；转码、进度记忆、多端同步都还是 Emby 原生能力。

播放地址有三种形态可选：

| 形态 | 特点 |
|---|---|
| 代理（默认） | 全部经 NAS 中转，兼容性最好 |
| **302 重定向（v0.6.0 新增）** | 播放时实时解析、回真 302 给播放器——**直链永不过期，且 NAS 不走流量** |
| 直链 | strm 直接写源站地址，外网播放器可以直接连（配合定时重解析防过期） |

302 模式用 ffmpeg 实测过解码；切换播放形态**即时生效，老的 strm 地址继续可用，不用重同步**。

## 解析能力（照着 TVBox 源码对齐）

- 传齐 `playerContent` 需要的 `vipFlags` —— 有些源不传就只给低清线路甚至直接"解析失败"
- 单线路失败自动**按集名换线路**重试；播放页类源带**网页嗅探**（苹果CMS `player_aaaa` / 嵌套 iframe / 正文里的 m3u8）
- **跨站换源**：一个条目在自己站点整条解不出时，自动去其它已同步站点搜同名影片（片名归一化 + 年份匹配），用能播的站写一份
- VIP 关键字、解析接口模板都可以在界面里自己配

实测数据：两跳源同一集二次播放 **6.18s → 0.43s**（302 缓存命中）；本次发布前对全库 **657 个 strm 逐个探测，全部可播，0 死链**。

## 库不会越养越脏

- **写库前先验活**：解析失败的条目不写库（宁可少一个，不要一墙死链）；直链写盘前 Range 探测，拿到报错页/防盗页自动退回代理
- **只写不删**：正常同步只写 strm/nfo/海报
- **清理有边界**：孤儿清理只删"我们写过、这次又不需要"的文件（有清单），单次删除超过上限直接停手；删除历史数据要二次确认输 `DELETE`，只动自己的两个子树

## 同步过程看得见

- 进度是**服务端推送**的（SSE）：正在处理哪个条目、已运行多久，实时显示
- 「同步记录」面板：最近 400 条条目级记录（写入/跳过/失败/换源），跳过带原因聚合（比如"9 集全部不可用（原因：404×8）"）——**哪个源在烂，一眼就能看出来**
- 默认 12 小时定时同步，支持增量（列表侧指纹没变就不重复拉详情）
- 配置支持**一键导出/导入**：换机器、多部署不用重配

## 其他细节

- **开箱即用**：fpk 内置裁剪版 JRE（x64 / arm64 自动选），系统不用装 Java
- 常驻内存压到 ~88MB（堆参数收紧 + 空闲自动清缓存）
- 所有网络接口只绑本机回环，Web 端点走令牌/同源校验
- Emby Server 4.9 / 4.10 均支持

## 适合谁 / 不适合谁

✅ 适合：想在 Emby 里获得海报墙体验、手里有可用 TVBox 点播源、玩 fnOS + Emby 的人

❌ 不适合：追求"开箱即有内容"的——**本应用不提供任何源**，源需要自备；另外 TVBox 配置里有一部分源把 spider 打成 Android dex 包，纯 JVM 跑不动，这类站点会显示不可用（诚实说，救不了）；网盘类源没账号拿不到直链，默认不采。

源站随时可能失效或改接口——这是第三方内容的天然属性，站点页的探测和同步记录页就是用来盯这件事的。
