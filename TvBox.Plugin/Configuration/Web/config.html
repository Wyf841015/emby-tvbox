TVBox 源接入

把 TVBox 配置里的点播源（苹果 CMS 接口，type 0/1）同步成 .strm 文件，Emby 扫描后即可浏览、搜索、播放。
注意：type 3/4 的 spider 源（jar / drpy js）无法解析，会被自动跳过。

支持单仓 JSON、多仓（urls）、base64 编码，也支持本机文件绝对路径。
会生成两个子目录：movies/（电影库）和 tv/（电视剧库）。 在 Emby 里分别添加这两个目录为媒体库。
开启播放代理时必须填，用于生成绝对播放地址。局域网内填内网 IP 即可。
填了之后，配置里 type:3 / api:csp_XXX 的 spider 站点会被自动改写成 <hub>/v/<key>/api.php/provide/vod/，当作普通采集站同步。 留空 = 跳过所有 spider 站点。
很多采集站的 m3u8 会校验 Referer，遇到 403 时在这里填源站地址。
打开后 strm 里写 /TvBox/Stream?u=...，由插件补 Referer/UA 并重写 HLS 分片地址，能解决防盗链。 代价是所有播放流量都经过 Emby。
填站点 key，逗号分隔。建议先用「查看站点」拿到 key 再填。
每页通常 20 条。源很脆弱，建议 1-3 页。
0 = 不限。第一次先填 20 试水，确认能跑通再放开。

同步行为

这些源只能在其自家 App 里播，同步进来也播不了，默认排除。
只对开了增量同步生效；填 0 = 每次全量。
开着「清理已失效的 strm」时，一次最多删多少，防止源抽风把库删空。

输出内容

写了 Emby 刮削更快，但条目多时文件数会翻倍。
只在 auto 模式下生效，逗号分隔。

探测与网络

能大幅减少写进库里的坏条目，代价是每集多一次请求。
2 核机器建议 2-4，源脆弱时调小。
只有把点播源放在自己内网时才需要打开。
